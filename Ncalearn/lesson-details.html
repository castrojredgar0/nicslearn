Lesson 1: HTML Basics

What is HTML?

HTML stands for HyperText Markup Language. It is the standard language used to create and structure webpages.

Basic HTML Structure

<!DOCTYPE html>
<html>

<head>
    <title>My Website</title>
</head>

<body>

    <h1>Hello World!</h1>

    <p>Welcome to my website.</p>

</body>

</html>

Important HTML Tags

HTML Tag Purpose
<h1> Creates a heading
<p> Creates a paragraph
<a> Creates a link
<img> Displays an image
v<table> Creates a table
